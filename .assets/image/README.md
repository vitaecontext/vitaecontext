# VitaeContext visual assets

Use current illustrations for public documentation. Preserve historical artwork for migration history; it does not describe the current module inventory.

## Current illustrations

- `public-visuals/vitaecontext/basic-workflow.png`: source material, Career Context building, MCP or bounded-summary reuse, and downstream tools. `public-visuals/workflow.png` is the same current workflow at the earlier asset path.
- `public-visuals/grounded-optimization.png`: evidence boundaries and downstream handoff; the filename is retained for existing consumers.
- `public-visuals/mcp/mcp-workflow.png`: selected local sources connected to project workspaces through stateless MCP.
- `public-visuals/mcp/mcp-capabilities.png`: heading discovery, bounded selection, graph search, and structural validation.
- `public-visuals/vitaegraph/`: current compact-context comparison and detailed-record structure. Platform examples are downstream uses, not bundled skills.
- `public-visuals/vitaecontext/workflow-use-case.png`: a downstream task using an existing context file.
- `preview/vitaecontext-social-preview.png`, `banners/vitaecontext/`, and `banners/vitaegraph/`: current brand artwork. Existing short slogans are visual variants; the canonical tagline is “Keep your career context. Reuse it across AI.”
- `logos/`: established brand marks and wordmarks.
